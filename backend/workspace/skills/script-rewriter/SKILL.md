# 剧本改写指南

## 改写原则

1. **保留核心情节**：不改变主线故事和角色关系
2. **增强画面感**：将叙述性文字转化为可视化的场景描写
3. **对话驱动**：用对白推动情节，减少旁白
4. **节奏把控**：每场戏控制在 10-20 秒——1-3 个动作节拍、最多 3 句对白。这是竖屏短剧：第一场就是钩子，每场戏都要有转折
5. **默认精简**：每个动作节拍一句话；单句台词不超过 20 个字（英文不超过 12 个词）；删掉寒暄、闲聊、重复信息和画面已经交代的内容
6. **不写镜头语言**：不涉及景别、角度、运镜，这些属于分镜拆解步骤

## 格式化剧本格式

```
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

### 角色表

剧本以角色表开头，位于 S01 之前，标题固定写作 `## Characters`：

```
## Characters

- 小明 — Appearance: 二十七八岁男性，东亚面孔，身形清瘦，眼神疲惫，微微驼背，神情戒备。Styling: 黑色凌乱短发，灰色连帽衫外搭旧牛仔夹克，银色手表。
- 小红 — Appearance: 二十五六岁女性，东亚面孔，娇小，眼睛明亮，笑容来得很快。Styling: 棕色及肩发，米色风衣，红围巾，小金耳钉。
```

- 每个有台词或重要动作的角色一行；名字必须与对白中的写法完全一致
- **Appearance**（外貌）：性别、年龄感、族裔或肤色、体型、五官、气质。性格要转化为看得见的神态，不写抽象性格词
- **Body**（身材，仅限成年角色）：在 `Styling` 之后追加 `Body: ……`，描述穿贴身平角内裤时的身材——体型、肌肉线条、肤色、体毛、纹身或疤痕。原文未说明时默认健身型、线条清晰、好看。未满 18 岁的角色不写 Body
- **Styling**（造型）：发型、带颜色和材质的服装、配饰——本集的穿着
- 原文给出的细节全部采用；原文没写的，结合故事和背景定下具体内容。不允许含糊（"休闲装"）或留空
- 角色表是给美术和提取环节的参考：不是一场戏，其中内容不会被念出来

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头
- 动作描写自然段 — 不包含任何镜头语言
- `角色名：（状态/表情）台词内容` — 对白格式

### 内容量参考

格式化剧本不应比原始内容更长，通常更短：把说明性文字压缩成一个可见动作或一句台词。一整集通常 60-120 秒。原文更长时，保留钩子、转折和爆点，其余删掉。绝不扩写。

## 改写步骤

1. 先调用 `read_episode_script` 读取原始内容
2. 分析内容结构（对话、叙述、心理描写的比例）
3. 调用 `rewrite_to_screenplay` 执行改写
4. 检查改写结果：以 `## Characters` 角色表开头并覆盖所有有台词的角色，且符合格式化剧本格式
5. 调用 `save_script` 保存最终结果

## 注意事项

- 心理描写可转化为角色表情/动作或画外音
- 长段叙述拆分为多个短场景
- 确保每个场景有明确的情绪转折点
- 保持角色语言风格一致性
- 场景编号连续递增（S01, S02, S03...）
- 时间段要具体（黄昏、深夜、清晨），不要笼统写"白天"
