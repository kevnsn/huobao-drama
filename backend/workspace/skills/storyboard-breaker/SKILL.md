# 分镜拆解指南

## 核心定义：分镜段落

一个分镜 = 一个 **分镜段落**（segment）= 一个视频生成任务。

- 这是竖屏短剧，剪辑要快：每个段落时长 **10-15 秒**，内部承载 **4-6 个子镜头**。段落要长，段内切镜保持紧凑。段落越少越长，连续性越好：同一次生成内模型自己会保持房间、服装和站位一致，段落之间的接缝才是漂移的来源。因此只有在换场景、站位状态改变（有人进出、坐下、起身、走到别处）或超过视频模型最长时长时才开新段落，绝不因为一句台词或一个节拍结束就切段
- 子镜头之间**可以切镜**：换景别、换角度、换拍摄对象，用硬切衔接
- 子镜头之间**不跨场景**：一个段落只发生在一个场景内（`scene_id` 是段落级绑定）
- 每个子镜头 **1-3 秒**，聚焦一个画面单元（一个动作、一个反应、一个特写）；单个子镜头不得超过 3 秒，宁可切到反应或细节

## 拆分流程（四步）

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、道具、已有分镜摘要
2. **节拍识别**：先识别剧本的叙事节拍——剧本中的【开场】【触发】【高潮】【收尾】等标记，或叙事转折点（地点转移、规则揭示、情绪爆发、反转）。**节拍边界强制切段**，同一节拍内的子镜头优先归入同一段落，不把一条因果链（铺垫-发生-反应）切散到不同段落
3. **总量锚定**：目标总时长 = 剧本中台词与旁白的朗读时长（中文约 4.5 字/秒，英文约 2.8 词/秒）+ 每个无台词动作节拍约 1 秒；一整集通常 60-120 秒；段落数 ≈ 目标总时长 ÷ 12秒，允许 ±20% 浮动。不要明显超出，拿不准就更短。剧本开头的 `## Characters` 角色表只是角色外观参考，不是一场戏，不为它生成段落，也不计入字数
4. **段落内拆子镜头**：按动作切换点、视角切换点、对象切换点切分子镜头，为每个段落补全完整字段后调用 `save_storyboards` 一次性保存

## 节奏分层时长

按段落功能确定时长，不要一刀切：

| 段落类型 | 时长 | 说明 |
|---|---|---|
| 钩子/过渡段 | 5-8 秒 | 赶路、空镜、环境建立、转场 |
| 叙事段 | 10-15 秒 | 常规剧情推进、对话 |
| 爆点段 | 10-15 秒 | 特写、规则揭示、情感爆发、反转；单个子镜头最多停留 3 秒 |

## 台词时长下限（硬规则）

**段落时长 ≥ 段内台词与旁白的朗读时长（写在 description 中的部分；中文约 4.5 字/秒，英文约 3 词/秒）+ 1 秒**；15 秒内装不下的台词删减或拆到下一个段落，不得为此拉长段落

装不下的台词必须拆到下一个段落，不允许把演不完的台词塞进一个段落。

## 场景锁定与连续性（硬性规则）

每个段落都是单独生成的视频，彼此看不到。没有重申的内容都会变。

- **场景锁定**：每个 `description` 以 `【Scene lock】` 开头（位于 `【Blocking】` 之前）。同一 scene_id 只定一次，并**逐字复制到该场景的每个段落**：房间的固定地标及其位置、每个角色的确切服装（取自角色表，不得改写）、各自手里拿的东西、坐着还是站着
- **状态变化向后传递**：某段落呈现了变化（坐下、放下杯子、脱外套）时，该段保留旧状态，之后所有段落的锁定更新为新状态。没有画面交代，任何人不得在段落之间从坐变站
- **站位左右固定**：场景第一个段落中在画左的角色，整个场景都在画左
- **每个段落接着上一个段落的结尾开始**：第一个子镜头与上一段最后的位置、姿态、视线一致

## 节奏（硬性规则）

- **开场即钩子**：全集第一个子镜头 1-2 秒，且已在动作或台词之中，不用静止的建立镜头开场
- **切镜长短要变化**：不得连续三个子镜头时长相同；1 秒的反应镜头与 2-3 秒的台词镜头交替
- **每场戏一个停顿**：在情绪最高点，允许一个子镜头停留最多 4 秒，其余保持 1-3 秒
- **结尾不留空白**：段落以台词、动作或不超过 1.5 秒的反应收尾，不得以更长的无声对视结束
- **台词铺满段落**：台词分布到各子镜头，让说话或有意义的动作持续到最后一秒

## 站位与表演（硬性规则）

视频模型不被告知时会随机安排人物。每个段落都必须写清人物在哪、看向哪。

- **站位行**：`description` 以 `【Blocking】` 开头（位于 `【镜头1】` 之前）——谁在空间中的哪个位置（画左/画右、前景/后景）、相距多远、**谁面向谁**
- **互相对话的人要互相看着对方**。每个有台词的子镜头都写明："A 面向 B，看着 B 的眼睛，说：……"。除非剧本写明回避眼神（那也要明确写出），否则不允许两个说话的人都面向镜头或朝同一方向
- **保持轴线**：角色一旦在画左，整个段落都在画左。对话使用正反打和过肩镜头
- **每个子镜头写明**：景别、看到谁的脸、视线落点、一个具体动作
- **情绪必须具体可见**：每个子镜头一个可见细节（吞咽、屏息、瞥向嘴唇、握紧杯子、迟到的微笑），不用抽象词
- **默认略微拉远**：多数子镜头用中景或中全景——腰部或膝部以上，对话双方、手部和关键动作都在画内，周围空间可见。对话优先用带过肩的双人镜头而非单人特写。紧特写和插入镜头只留给段落中最关键的一两个节拍
- **电影感**：有纵深的构图（前景元素、人物、有生气的背景）；有来源的布光（场景内灯具、窗光、勾勒人物的轮廓光）；每个段落安排一个有意图的运镜（缓推、横移、两人之间的焦点转移、轻微手持呼吸感），避免死板固定机位；浅景深，克制的电影调色
- **构图**：景别、机位角度与高度、主体在竖屏画面中的位置、焦点虚实
- **背景**：该机位下主体身后的具体内容——陈设细节、群演在做什么、光源。反打镜头看到的是房间另一侧；跨切镜保持与场景一致
- **声音**：每句台词都写出语气——音调、语速、音量（"低声、干涩，几乎是自言自语地说："），不允许只写"说"
- **反应**：每句台词都要有听者的可见反应，写在同一子镜头或下一个切镜里
- **为情绪而切**：每句台词先给说话人，再切听者反应；关键节拍加插入特写（手、杯子、眼睛）。两人对话至少是 说话人 → 反应 → 说话人，绝不用一个固定双人镜头撑完

## 镜头要素

1. **镜头标题**：3-5字概括段落核心内容（如"噩梦惊醒"）
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局 + 环境细节
4. **景别**：段落内主导景别；多景别段落写组合，如"中景+特写"
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推镜/拉镜/摇镜/跟镜/移镜（段落内不同子镜头可不同）
7. **画面描述** `description`：按 `【镜头1】…【镜头2】…` 逐子镜头描述观众实际看到和听到的内容——画面（谁 + 具体动作 + 肢体细节 + 表情）写在前；该子镜头有台词时以「角色名说：「台词」」写在对应 `【镜头N】` 内，旁白写「旁白：内容」
8. **画面结果** `result`：段落结尾的即时后果 + 视觉细节
9. **氛围** `atmosphere`：光线 + 色调 + 声音 + 整体氛围
10. **时长** `duration`：段落总时长 10-15 秒（不得超过视频模型最长时长；仅独立的钩子/过渡段可为 5-8 秒）（多数视频模型最短 4 秒），且满足台词时长下限
11. **场景关联**：若能匹配已有场景，必须填写 `scene_id`
12. **角色关联**：填写 `character_ids`，绑定当前段落涉及的 0 到多个角色
13. **道具关联**：填写 `prop_ids`，绑定当前段落出现的关键道具（0 到多个）

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`
- `location + time` 可明确匹配时，必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择
- 一个段落可以没有角色，也可以绑定多个角色
- 只要段落里有明确出场、被看见、发生动作或说话的角色，都应绑定进去
- 纯环境段落、空镜、物件特写可以传空数组

## 道具绑定规则

- `prop_ids` 必须从 `read_storyboard_context` 返回的道具列表（`props`）中选择
- 道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到该段落
- 道具特写段落（无角色）也应绑定道具，`character_ids` 可为空
- 与剧情无关的背景物品、场景陈设不要绑定；没有道具出现的段落传空数组
- 绑定的道具会作为视频生成的参考图（白底单品图），保证道具外观跨段落一致

## 质量要求

- `description` 要适合人读，按子镜头详细描述观众实际看到和听到的内容；台词/旁白直接写在对应 `【镜头N】` 内
- `image_prompt` 要突出单帧构图、角色外观、环境和光线（对应段落第一个子镜头）
- `bgm_prompt` 和 `sound_effect` 用简洁短语即可，但不能空泛到只有“紧张”“悲伤”
- 如需调整，调用 `update_storyboard` 修改具体段落
